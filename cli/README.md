# CLI Directory

The `cli` directory contains the CLI application workspace package for Santra.

## Purpose
- **CLI Application**: Provides a command-line interface for interacting with Santra's features.

## Getting Started

To run the CLI in development mode, use the following command:

```bash
bun run --filter @santra/cli dev
```

## Key Files
- **README.md**: Provides instructions for running the CLI in development mode.
- **index.ts**: Main entry point for the CLI.
