# Santra CLI

A command-line interface for Santra.
## Project Structure
The project consists of the following directories and files:
- index.tsx
- App.tsx
- types
- components
- hooks
## Functionality
The App.tsx file is the main entry point of the application. It renders a user interface with a sidebar, a main panel, and a status bar. The sidebar displays tasks and files, while the main panel displays the agent log, diff, or output. The status bar displays statistics and input suggestions.
