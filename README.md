# Santra Project
Santra monorepo for CLI, web, backend, and shared packages.

## Project Structure
- core: Core functionality of the project
- web: Web application
- agents: Agents for the project
- cli: Command Line Interface for the project
- packages: Shared packages for the project

## Running the Project
- Web: Run with `npm run web`
- CLI: Run with `npm run cli`
- TUI: Run with `npm run tui`
- Typecheck: Run with `npm run typecheck`
